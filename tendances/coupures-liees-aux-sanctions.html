Coupures liées aux sanctions

Axe juridique · urgence faible

Ce qui se passe

Après des sanctions américaines en février 2025, le procureur de la Cour pénale internationale a perdu l’accès à sa messagerie Microsoft et a dû changer de fournisseur, selon l’Associated Press. Microsoft conteste avoir coupé les services de la Cour.

Le déclencheur

En 2025, le procureur de la Cour pénale internationale a perdu l’accès à sa messagerie après des sanctions américaines : un risque jusque-là théorique est devenu concret.

Le risque pour votre organisation

Un service peut devenir inaccessible pour des raisons qui n’ont rien de technique ni de contractuel.

Technologies concernées

  • Entra ID et Active Directory
  • Huawei DCS (FusionCompute)
  • Kubernetes managé (EKS, AKS, GKE)
  • Machines virtuelles AWS (EC2)
  • Machines virtuelles Azure
  • Microsoft Defender
  • Microsoft Intune

Comment l’enfermement se met en place

  • Extraterritorialité et sanctions. Des lois étrangères peuvent imposer l’accès aux données ou l’interruption d’un service.
  • Suspension ou résiliation unilatérale du service. Le contrat permet au fournisseur de couper ou de suspendre le service sans préavis suffisant ni recours.
  • Contrôles à l’exportation. Des restrictions sur les puces ou les technologies peuvent limiter l’accès à un service.
  • Séquestre de code source sans droit d’usage effectif. Le fournisseur propose un dépôt du code source en lieu sûr pour rassurer sur la continuité, mais le droit de l’utiliser, de le modifier et de l’héberger n’est ni défini ni opérationnel.

Les leviers pour garder le choix

  • Cartographie et classification des données. Identifiez les services critiques exposés à un droit étranger.
  • Mode dégradé et continuité hors fournisseur. Prévoyez un mode dégradé pour les plus sensibles.
  • Séquestre de code source exploitable. Exigez un séquestre de code source avec droit d’usage effectif pour les logiciels critiques.
