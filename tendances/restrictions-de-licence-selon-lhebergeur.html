Restrictions de licence selon l’hébergeur

Axe juridique · urgence moyenne

Ce qui se passe

Certaines licences coûtent plus cher, ou ne peuvent pas être transférées, chez des clouds concurrents de l’éditeur. Ces pratiques ont fait l’objet de plaintes en Europe, dont celle de CISPE contre Microsoft, réglée en 2024.

Le déclencheur

La plainte de CISPE contre Microsoft, réglée en 2024 par un accord, a mis en lumière l’impact des règles de licence sur le choix des hébergeurs.

Le risque pour votre organisation

Le choix de l’hébergeur est contraint par les licences, et non par l’offre technique.

Technologies concernées

  • Azure Virtual Desktop
  • Microsoft SQL Server
  • Oracle Database
  • Windows Server

Comment l’enfermement se met en place

  • Restrictions selon l’hébergeur. Des licences plus chères, ou non transférables, chez un cloud concurrent de l’éditeur.
  • Virtualisation non reconnue comme sous-capacité. L’éditeur refuse de compter les cœurs attribués à une machine virtuelle et exige de licencier les cœurs physiques du serveur.

Les leviers pour garder le choix

  • Revue de réversibilité des nouveaux contrats. Vérifiez les droits de transfert de chaque licence avant de choisir un hébergeur.
  • Coût total de la dépendance. Chiffrez le coût des licences dans chaque scénario d’hébergement.

Sources
