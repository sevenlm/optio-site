Pipelines liés à la forge

Axe pratiques technologiques · urgence moyenne

Ce qui se passe

Les pipelines de livraison s’écrivent dans le format de la forge qui les exécute. GitHub a montré qu’un service que l’on croyait gratuit parce qu’on fournit son propre matériel peut devenir payant : le 16 décembre 2025, il a annoncé un tarif de 0,002 $ par minute pour tous les travaux Actions des dépôts privés, y compris sur des exécuteurs auto-hébergés, à partir du 1er mars 2026. Sous la pression des utilisateurs, GitHub a ensuite reporté ce changement de facturation pour le réévaluer, tout en maintenant la baisse de prix de ses exécuteurs hébergés.

Le déclencheur

Le 16 décembre 2025, GitHub a annoncé une facturation de 0,002 $ par minute pour les exécuteurs auto-hébergés de GitHub Actions dès le 1er mars 2026, avant de reporter cette mesure.

Le risque pour votre organisation

Les pipelines, les actions réutilisées et les secrets sont propres à la forge : la changer, ou subir une hausse, oblige à réécrire la chaîne de livraison.

Comment l’enfermement se met en place

  • Intégrations d’écosystème. L’identité, la supervision et les outils annexes sont imposés par le fournisseur.
  • Coût d’entrée nul, coût de sortie élevé. Crédits gratuits, essais, prix d’appel, puis montée en charge.

Les leviers pour garder le choix

  • Couches d’abstraction. Gardez la logique de build et de déploiement dans des scripts versionnés que la forge se contente d’appeler.
  • Registre des contrats et des prestataires. Inventoriez les pipelines et les actions tierces dont ils dépendent, et chiffrez leur coût mensuel d’exécution.
  • Tests de bascule réguliers. Testez l’exécution d’un pipeline critique sur un second outil de CI/CD.
  • Cartographie du chemin vers la production. Repérez les étapes de livraison qui ne tiennent qu’à la forge, et rejouez-les ailleurs.
