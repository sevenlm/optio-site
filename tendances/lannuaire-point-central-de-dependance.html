L’annuaire, point central de dépendance

Axe pratiques technologiques · urgence forte

Ce qui se passe

Postes de travail, applications SaaS et cloud s’authentifient auprès du même service d’identité, alors qu’une entreprise utilise en moyenne 101 applications selon Okta (2025). Le 29 octobre 2025, une panne chez Microsoft a suffi à perturber les connexions à Microsoft 365 et à Entra.

Le déclencheur

Avec la généralisation du SaaS, l’annuaire est devenu la porte d’entrée de la plupart des applications, et donc un point de dépendance critique.

Le risque pour votre organisation

Si ce service est indisponible ou coupé, plus rien ne fonctionne : c’est le point de dépendance le plus central du système d’information.

Technologies concernées

  • Azure Virtual Desktop
  • Citrix Virtual Apps and Desktops
  • Entra ID et Active Directory
  • FreeIPA
  • Microsoft Defender
  • Microsoft Intune
  • Okta
  • Samba
  • Windows Server

Comment l’enfermement se met en place

  • Intégrations d’écosystème. L’identité, la supervision et les outils annexes sont imposés par le fournisseur.

Les leviers pour garder le choix

  • Mode dégradé et continuité hors fournisseur. Prévoyez un mode d’authentification de secours pour les accès critiques.
  • Couches d’abstraction. Appuyez-vous sur des protocoles standards (SAML, OpenID Connect) pour faciliter un changement.
