Couplage fort à la plateforme

Axe pratiques technologiques · urgence moyenne

Ce qui se passe

En 2023, l’équipe de Prime Video chargée de surveiller la qualité des flux vidéo a abandonné une architecture distribuée fondée sur AWS Step Functions et Amazon S3. Les transitions d’état effectuées à chaque seconde de flux atteignaient les limites du compte, et le passage à une application monolithique a réduit le coût d’infrastructure de plus de 90 %. En août 2023, Datadog observait que plus de 70 % de ses clients AWS utilisaient au moins un service sans serveur.

Le déclencheur

Le rapport de MuleSoft publié le 5 février 2026 compte en moyenne 957 applications par entreprise, contre 897 un an plus tôt, dont seulement 27 % intégrées entre elles.

Le risque pour votre organisation

Chaque microservice bâti sur une file de messages, une fonction sans serveur ou un orchestrateur propre à un cloud ajoute un point d’adhérence, et la logique métier qui y est logée ne se transpose pas ailleurs sans réécriture.

Technologies concernées

  • Amazon DynamoDB
  • Amazon S3
  • Amazon SQS et SNS
  • Apigee
  • AWS Lambda
  • AWS Step Functions
  • Azure Cosmos DB
  • Azure Functions
  • Azure Service Bus et Event Hubs
  • Google Cloud Functions
  • Google Pub/Sub
  • MuleSoft

Comment l’enfermement se met en place

  • Services managés sans équivalent. Des services propres à un cloud, sans équivalent direct ailleurs.
  • Intégrations d’écosystème. L’identité, la supervision et les outils annexes sont imposés par le fournisseur.
  • Langages et extensions propriétaires. Le code métier est écrit dans un langage propre au produit.

Les leviers pour garder le choix

  • Registre des contrats et des prestataires. Cartographiez, pour chaque microservice, les services propres au fournisseur qu’il appelle.
  • Couches d’abstraction. Isolez ces appels derrière des interfaces internes, gardez la logique métier dans votre code et remplacez les intégrations point à point par des API documentées et gouvernées.
  • Contrôles automatiques de réversibilité. Bloquez automatiquement les appels propriétaires qui contournent la couche d’abstraction.
  • Indice de réversibilité fondé sur la preuve. Mesurez le couplage réel de chaque application critique à sa plateforme, preuves à l’appui.
