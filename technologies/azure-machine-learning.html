Sortir de Azure Machine Learning

Microsoft · Données · Propriétaire

Sortie exigeante

Pourquoi la sortie est exigeante

Aucune licence à part, mais pipelines, registres et points d’accès s’appuient sur les autres services Azure consommés, qu’il faut remplacer en même temps.

Ce qui crée la dépendance

Service d’apprentissage automatique d’Azure, sans frais propres : on paie le calcul et les services Azure associés (Blob Storage, Key Vault, Container Registry, Application Insights). Pipelines, registres et points d’accès sont gérés ; la préparation Spark est interopérable avec Microsoft Fabric.

Alternatives à Azure Machine Learning

  • MLflow (sortie facilitée)
  • Kubeflow (sortie facilitée)
