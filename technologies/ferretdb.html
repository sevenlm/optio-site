Sortir de FerretDB

FerretDB · Données · Ouvert ou source disponible, éditeur unique

Sortie maîtrisable

Pourquoi la sortie est maîtrisable

Licence Apache 2.0 et données stockées dans PostgreSQL : la sortie est directe ; la compatibilité avec MongoDB est partielle et le projet est mené par un seul éditeur.

Ce qui crée la dépendance

Proxy compatible MongoDB sur PostgreSQL avec l’extension DocumentDB ; projet porté par FerretDB Inc.

Alternatives à FerretDB

  • MongoDB (sortie maîtrisable)
  • DocumentDB (sortie facilitée)
  • PostgreSQL (sortie facilitée)
  • Apache Cassandra (sortie facilitée)
