Pourquoi la sortie est exigeante

Le code se réutilise, mais les déclencheurs et liaisons propres à Azure et l’hébergement dans le compte Azure sont à reconstruire.

Ce qui crée la dépendance

Applications et agents événementiels sans serveur, écrits en C#, Java, JavaScript, PowerShell, Python ou Go et exécutés sur Azure.
