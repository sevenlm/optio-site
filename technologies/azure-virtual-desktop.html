Sortir de Azure Virtual Desktop

Microsoft · Middleware · Propriétaire

Sortie exigeante

Pourquoi la sortie est exigeante

Entra ID est toujours utilisé pour authentifier, et Windows 11 Enterprise multi-session n’existe que sur ce service. Les images et applications se reprennent chez Citrix ou Omnissa, mais l’identité, le profil FSLogix et les licences sont à reconstruire.

Ce qui crée la dépendance

Service Azure lié à Microsoft Entra ID, aux licences Windows ou Microsoft 365 et aux clients Microsoft ; Windows 10 et 11 Enterprise multi-session n’existent que dans Azure Virtual Desktop.

Alternatives à Azure Virtual Desktop

  • Citrix Virtual Apps and Desktops (sortie exigeante)
  • Omnissa Horizon (sortie exigeante)

Tendances qui concernent Azure Virtual Desktop

  • L’annuaire, point central de dépendance (urgence forte)
  • Restrictions de licence selon l’hébergeur (urgence moyenne)
