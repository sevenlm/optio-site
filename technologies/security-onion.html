Sortir de Security Onion

Security Onion Solutions · Services aux opérations · Ouvert ou source disponible, éditeur unique

Sortie maîtrisable

Pourquoi la sortie est maîtrisable

Code disponible et plateforme installable chez soi, mais licence Elastic 2.0 (non libre) et éditeur unique. Données dans Elasticsearch et règles aux formats standards, donc sortie maîtrisable.

Ce qui crée la dépendance

Plateforme de détection et de chasse (Suricata, Zeek, Elastic) sous Elastic License 2.0, avec édition Pro de l’éditeur.

Alternatives à Security Onion

  • Wazuh (sortie facilitée)
  • Elastic Security (sortie maîtrisable)

Tendances qui concernent Security Onion

  • Pénurie de compétences cyber face à NIS2 (urgence forte)
  • Changements de licence open source (urgence moyenne)
