Sortir de Garage

Deuxfleurs · Infrastructure bas niveau · Ouvert, gouvernance partagée

Sortie facilitée

Pourquoi la sortie est facilitée

L’API S3 et un code sous AGPL permettent de copier les données vers un autre stockage objet ; le projet est porté par Deuxfleurs, une association à but non lucratif, plutôt que par un éditeur commercial. Le sous-ensemble S3 géré est limité : les applications sont à vérifier avant de migrer.

Ce qui crée la dépendance

Stockage objet ouvert (AGPL) à API S3 partielle, porté par une association à but non lucratif.

Alternatives à Garage

  • Ceph (sortie facilitée)
  • SeaweedFS (sortie facilitée)
