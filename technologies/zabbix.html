Sortie facilitée

Pourquoi la sortie est facilitée

Code ouvert installable chez soi, avec API JSON et modèles exportables ; Prometheus offre un substitut ouvert à gouvernance partagée. Le passage à l’AGPL en 7.0 et l’éditeur unique pèsent peu sur la sortie.

Ce qui crée la dépendance

Supervision ouverte (agents, SNMP, modèles) pilotée par un éditeur unique ; licence AGPL depuis la version 7.0.
