Sortir de Azure Cosmos DB

Microsoft · Données · Propriétaire

Sortie difficile

Pourquoi la sortie est difficile

Service propriétaire aux API et modèles spécifiques : il faut adapter le code et le modèle de données.

Ce qui crée la dépendance

Service managé propriétaire, modèles et API spécifiques.

Alternatives à Azure Cosmos DB

  • PostgreSQL (sortie facilitée)
  • Apache Cassandra (sortie facilitée)
  • MongoDB (sortie maîtrisable)
  • DocumentDB (sortie facilitée)

Tendances qui concernent Azure Cosmos DB

  • Plans de sortie testés (DORA) (urgence forte)
  • Services managés propriétaires (urgence forte)
  • Accès extraterritorial aux données (urgence élevée)
  • Engagements de consommation cloud (urgence élevée)
  • Hébergement qualifié imposé (urgence élevée)
  • Couplage fort à la plateforme (urgence moyenne)
