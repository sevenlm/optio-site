Sortir de Entra ID et Active Directory

Microsoft · Middleware · Propriétaire

Sortie difficile

Pourquoi la sortie est difficile

Toutes les applications et tous les postes s’y authentifient : le changer touche l’ensemble du système d’information, sur une longue période.

Ce qui crée la dépendance

Tout le système d’information s’y authentifie : le point de dépendance le plus central.

Alternatives à Entra ID et Active Directory

  • Keycloak (sortie facilitée)
  • FreeIPA (sortie maîtrisable)
  • Samba (sortie maîtrisable)
  • Authentik (sortie facilitée)

Tendances qui concernent Entra ID et Active Directory

  • IA intégrée d’office dans les suites (urgence forte)
  • L’annuaire, point central de dépendance (urgence forte)
  • Plans de réduction des dépendances de l’État (urgence forte)
  • Plans de sortie testés (DORA) (urgence forte)
  • Accès extraterritorial aux données (urgence élevée)
  • Loi Résilience (NIS 2) (urgence élevée)
  • Coupures liées aux sanctions (urgence faible)
