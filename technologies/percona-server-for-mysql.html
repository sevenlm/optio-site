Sortir de Percona Server for MySQL

Percona · Données · Ouvert ou source disponible, éditeur unique

Sortie maîtrisable

Pourquoi la sortie est maîtrisable

Remplaçant direct de MySQL, même format et mêmes outils ; il suit le code d’Oracle et dépend d’un seul éditeur, d’où un anneau identique à MySQL.

Ce qui crée la dépendance

Dérivé de MySQL sous GPLv2, développé par Percona.

Alternatives à Percona Server for MySQL

  • MySQL (sortie maîtrisable)
  • MariaDB (sortie facilitée)
  • PostgreSQL (sortie facilitée)
  • YugabyteDB (sortie maîtrisable)
