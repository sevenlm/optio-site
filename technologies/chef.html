Sortie maîtrisable

Pourquoi la sortie est maîtrisable

Le code reste ouvert, mais l’usage de binaires officiels se paie en entreprise ; les recettes Ruby sont à réécrire pour changer d’outil.

Ce qui crée la dépendance

Code source sous licence Apache 2.0, mais les binaires distribués par Progress relèvent d’un contrat de licence : l’usage gratuit exclut les entreprises, un usage commercial exige une licence payante. Recettes Ruby propres à Chef.

Alternatives à Chef

  • Ansible (sortie facilitée)
  • OpenVox (sortie facilitée)

Sources

  • Chef, Licence du dépôt chef/chef, consulté en novembre 2026
