Sortir de OpenNebula

OpenNebula Systems · Infrastructure bas niveau · Ouvert ou source disponible, éditeur unique

Sortie maîtrisable

Pourquoi la sortie est maîtrisable

Le code source est ouvert sous licence Apache 2.0 et repose sur KVM, donc les machines virtuelles se reprennent. Les versions Enterprise et leurs correctifs sont réservées aux abonnés d’un éditeur unique, ce qui évite l’anneau extérieur.

Ce qui crée la dépendance

Plateforme de cloud privé à code ouvert (Apache 2.0), mais l’édition Enterprise, les mises à jour de maintenance et le support dépendent d’un seul éditeur sous abonnement.

Alternatives à OpenNebula

  • OpenStack (sortie maîtrisable)
  • Proxmox VE (sortie facilitée)
  • Incus (sortie facilitée)
  • KVM et QEMU (sortie facilitée)
