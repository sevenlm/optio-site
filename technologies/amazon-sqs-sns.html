Sortir de Amazon SQS et SNS

Amazon Web Services · Middleware · Propriétaire

Sortie exigeante

Pourquoi la sortie est exigeante

Les files se remplacent par un courtier ouvert, mais les applications utilisent les API et les droits IAM d’AWS, et les déclencheurs Lambda en dépendent.

Ce qui crée la dépendance

Files de messages et notifications gérées par AWS pour découpler microservices, systèmes distribués et applications sans serveur, avec envoi vers SMS, notifications mobiles et courriel pour SNS.

Alternatives à Amazon SQS et SNS

  • Apache Kafka (sortie facilitée)
  • RabbitMQ (sortie maîtrisable)
  • NATS JetStream (sortie facilitée)

Tendances qui concernent Amazon SQS et SNS

  • Couplage fort à la plateforme (urgence moyenne)
