Sortie maîtrisable

Pourquoi la sortie est maîtrisable

Format et protocole repris par MariaDB et de nombreux services : la sortie est maîtrisable ; le contrôle par un seul éditeur l’éloigne de l’anneau extérieur.

Ce qui crée la dépendance

Code ouvert, mais projet contrôlé par Oracle.

Alternatives à MySQL

  • MariaDB (sortie facilitée)
  • PostgreSQL (sortie facilitée)
  • Percona Server for MySQL (sortie maîtrisable)
