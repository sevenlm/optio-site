Pourquoi la sortie est facilitée

Licence permissive, auto-hébergement documenté, pas de compte imposé ; peu de données à migrer, la visioconférence étant éphémère.

Ce qui crée la dépendance

Code sous licence Apache 2.0. Le projet propose paquets Debian et Docker pour l’auto-hébergement, et 8x8 vend une offre hébergée du même logiciel.
