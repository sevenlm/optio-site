Sortir de Microsoft SQL Server

Microsoft · Données · Propriétaire

Sortie exigeante

Pourquoi la sortie est exigeante

Le T-SQL et les fonctions spécifiques sont à adapter ; des outils de conversion existent, mais la migration reste lourde.

Ce qui crée la dépendance

Langage T-SQL spécifique, licences par cœur ou, pour l’édition Standard, par serveur et accès client (CAL).

Alternatives à Microsoft SQL Server

  • PostgreSQL (sortie facilitée)

Tendances qui concernent Microsoft SQL Server

  • Audits de licence comme levier commercial (urgence forte)
  • Changements de métrique de licence (urgence forte)
  • Fins de support imposées (urgence forte)
  • Plans de réduction des dépendances de l’État (urgence forte)
  • Restrictions de licence selon l’hébergeur (urgence moyenne)

Sources

  • Microsoft, Tarification de SQL Server 2022, consulté en novembre 2026
