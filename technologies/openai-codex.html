Pourquoi la sortie est maîtrisable

Client ouvert et instructions au format AGENTS.md, mais le service cloud, la facturation et les modèles restent ceux d’OpenAI.

Ce qui crée la dépendance

Agent de code d’OpenAI (ligne de commande, éditeurs, cloud), inclus dans les offres ChatGPT. L’outil en ligne de commande est sous licence Apache 2.0 ; le service et les modèles sont propriétaires.
