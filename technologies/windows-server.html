Sortir de Windows Server

Microsoft · Infrastructure bas niveau · Propriétaire

Sortie exigeante

Pourquoi la sortie est exigeante

Les applications écrites pour Windows ne se déplacent pas vers Linux sans adaptation, et les licences sont liées à la virtualisation et à l’annuaire : la migration est lourde.

Ce qui crée la dépendance

Licences par cœur et accès clients, liées à la virtualisation et à l’annuaire ; le support principal de Windows Server 2022 a pris fin le 13 octobre 2026 (support étendu jusqu’en 2031), Windows Server 2025 étant la version courante.

Alternatives à Windows Server

  • Debian (sortie facilitée)
  • AlmaLinux et Rocky Linux (sortie facilitée)
  • Samba (sortie maîtrisable)

Tendances qui concernent Windows Server

  • Audits de licence comme levier commercial (urgence forte)
  • Changements de métrique de licence (urgence forte)
  • Fins de support imposées (urgence forte)
  • L’annuaire, point central de dépendance (urgence forte)
  • Virtualisation propriétaire (urgence forte)
  • Restrictions de licence selon l’hébergeur (urgence moyenne)
