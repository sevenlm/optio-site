Sortir de Red Hat Enterprise Linux

Red Hat (IBM) · Infrastructure bas niveau · Ouvert ou source disponible, éditeur unique

Sortie maîtrisable

Pourquoi la sortie est maîtrisable

Les applications fonctionnent sur des distributions compatibles, ce qui rend la sortie maîtrisable ; la souscription et l’accès restreint aux sources l’empêchent d’être dans l’anneau extérieur.

Ce qui crée la dépendance

Code ouvert, mais accès aux sources restreint depuis 2023 et modèle par souscription.

Alternatives à Red Hat Enterprise Linux

  • AlmaLinux et Rocky Linux (sortie facilitée)
  • Debian (sortie facilitée)
  • Ubuntu Server (sortie facilitée)
  • Oracle Linux (sortie maîtrisable)

Tendances qui concernent Red Hat Enterprise Linux

  • Changements de licence open source (urgence moyenne)

Sources
