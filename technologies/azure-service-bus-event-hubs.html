Sortir de Azure Service Bus et Event Hubs

Microsoft · Middleware · Propriétaire

Sortie exigeante

Pourquoi la sortie est exigeante

Le support de JMS facilite l’arrivée comme le départ pour les applications Java, mais les autres usages passent par les API et les droits d’Azure.

Ce qui crée la dépendance

Messagerie cloud d’Azure reliant applications et appareils (Service Bus) et ingestion de flux massifs (Event Hubs). Service Bus accepte les applications Java Message Service (JMS) existantes.

Alternatives à Azure Service Bus et Event Hubs

  • Apache Kafka (sortie facilitée)
  • RabbitMQ (sortie maîtrisable)
  • NATS JetStream (sortie facilitée)

Tendances qui concernent Azure Service Bus et Event Hubs

  • Couplage fort à la plateforme (urgence moyenne)
