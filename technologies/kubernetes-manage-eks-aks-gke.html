Sortie maîtrisable

Pourquoi la sortie est maîtrisable

Kubernetes est standard et les applications se déplacent ; les intégrations propres à chaque cloud (identité, réseau, stockage) demandent une adaptation.

Ce qui crée la dépendance

Kubernetes standard, mais intégrations propres à chaque cloud.
