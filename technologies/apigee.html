Sortir de Apigee

Google · Middleware · Propriétaire

Sortie exigeante

Pourquoi la sortie est exigeante

Les politiques d’API sont décrites dans le format de l’outil et liées à Google Cloud : il faut les reprendre une par une.

Ce qui crée la dépendance

Gestion d’API propriétaire, intégrée à Google Cloud.

Alternatives à Apigee

  • Kong Gateway (sortie maîtrisable)
  • Gravitee (sortie maîtrisable)
  • Apache APISIX (sortie facilitée)
  • WSO2 (API Manager et Integrator) (sortie maîtrisable)
  • Azure API Management (sortie exigeante)

Tendances qui concernent Apigee

  • Services managés propriétaires (urgence forte)
  • Couplage fort à la plateforme (urgence moyenne)
