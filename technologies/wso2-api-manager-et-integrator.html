Sortir de WSO2 (API Manager et Integrator)

WSO2 · Middleware · Ouvert ou source disponible, éditeur unique

Sortie maîtrisable

Pourquoi la sortie est maîtrisable

Le cœur est sous Apache 2.0 et les API s’appuient sur OpenAPI. Les politiques, médiations et portails propres à WSO2 sont à reconstruire. Un seul éditeur contrôle la feuille de route et le support.

Ce qui crée la dépendance

Plateforme de gestion d’API et d’intégration ouverte (Apache 2.0) mais pilotée par un seul éditeur ; support, versions maintenues et offres cloud sous abonnement.

Alternatives à WSO2 (API Manager et Integrator)

  • Apache APISIX (sortie facilitée)
  • Kong Gateway (sortie maîtrisable)
  • Gravitee (sortie maîtrisable)
  • Apache Camel (sortie facilitée)
