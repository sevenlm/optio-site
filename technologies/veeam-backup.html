Sortir de Veeam Backup

Veeam · Infrastructure bas niveau · Propriétaire

Sortie exigeante

Pourquoi la sortie est exigeante

Les sauvegardes existantes ne se restaurent qu’avec l’outil : changer impose de garder l’ancien le temps de la rétention, d’où une sortie exigeante.

Ce qui crée la dépendance

Formats de sauvegarde propriétaires : la restauration dépend de l’outil.

Alternatives à Veeam Backup

  • Bacula (sortie maîtrisable)
  • Bareos (sortie maîtrisable)
  • Proxmox Backup Server (sortie maîtrisable)

Tendances qui concernent Veeam Backup

  • Plans de sortie testés (DORA) (urgence forte)
  • Loi Résilience (NIS 2) (urgence élevée)
