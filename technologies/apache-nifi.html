Sortir de Apache NiFi

Apache Software Foundation · Données · Ouvert, gouvernance partagée

Sortie facilitée

Pourquoi la sortie est facilitée

Projet de la fondation Apache sous licence Apache 2.0, flux exportables en JSON. Les définitions de flux ne s’importent pas dans un autre outil : il faut reconstruire les flux, mais sans verrou de licence ni d’éditeur.

Ce qui crée la dépendance

Flux de données décrits dans l’interface NiFi (flux versionnés au format JSON), traitements propres à NiFi.
