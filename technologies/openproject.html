Sortir de OpenProject

OpenProject GmbH · Services aux opérations · Ouvert ou source disponible, éditeur unique

Sortie facilitée

Pourquoi la sortie est facilitée

Code ouvert sous GPLv3 (édition communautaire), installable chez soi ou chez un prestataire, avec une API standard. Un éditeur principal vend des extensions payantes, mais l’édition communautaire reste utilisable.

Ce qui crée la dépendance

Gestion de projet ouverte (GPLv3), extensions entreprise payantes, éditeur principal.
