Sortir de AWS Outposts

Amazon Web Services · Infrastructure bas niveau · Propriétaire

Sortie difficile

Pourquoi la sortie est difficile

Matériel propriété d’AWS, piloté depuis une région AWS et engagé sur trois ans : la sortie dépend du calendrier du contrat et d’une infrastructure de remplacement.

Ce qui crée la dépendance

Matériel AWS installé dans vos locaux, piloté depuis une région AWS et engagé sur trois ans.

Alternatives à AWS Outposts

  • Proxmox VE (sortie facilitée)
  • OpenStack (sortie maîtrisable)
  • Apache CloudStack (sortie maîtrisable)
  • OpenNebula (sortie maîtrisable)

Tendances qui concernent AWS Outposts

  • Services managés propriétaires (urgence forte)
  • Concentration des régions cloud (urgence moyenne)
