Sortie maîtrisable

Pourquoi la sortie est maîtrisable

Le fork Valkey, compatible, offre une sortie directe ; les changements de licence montrent le poids d’un seul éditeur.

Ce qui crée la dépendance

Licence modifiée en 2024 ; une option AGPL a été réintroduite en 2025, après la création du fork Valkey.

Alternatives à Redis

  • Valkey (sortie facilitée)
  • Dragonfly (sortie maîtrisable)

Tendances qui concernent Redis

  • Changements de licence open source (urgence moyenne)
